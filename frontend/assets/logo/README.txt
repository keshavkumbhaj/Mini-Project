==================================================
ROZ MARRA LOGO ASSET DIRECTORY
==================================================

To use the official ROZ MARRA logo asset in the dashboard:

1. Place your official logo image file in this directory with the filename:
   logo.png (or logo.svg)

2. The application is configured to automatically detect and load:
   assets/logo/logo.png
   or fallback to:
   assets/logo/rozmarra-logo.svg

Brand guidelines:
- Custom geometric ROZ MARRA lettering
- Distinctive curved/angular letter cuts
- Cyan (#60E0FF) -> Blue (#4F8BFF) -> Purple (#8B5CF6) gradient
- Dark background compatible (#0B0F14 / #10151C)
- Do NOT use pink or flashy neon effects
